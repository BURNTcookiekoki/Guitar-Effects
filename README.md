The Modded Boss DS1 pedal includes 3 knobs gain, level and tone with 8 extra options to change the type of distortion and bypass switch

I have created this project as both buying many analog pedals or a whole multiboard can be expensive so I thought about creating a cheaper alternative with more options so I dont need to change pedals.

It features 3 potentiometers to control gain, level and tone with an extra 8 options ( 4 for each option ) to change the intensity or power of the distortion too gives sounds of metal, blues and pushed pedal sounds, also has a switch to bypass the signal.

<img width="921" height="597" alt="CE4" src="https://github.com/user-attachments/assets/2380c140-780d-4f67-9536-8f8c0b971f7b" />
This is the image of my 3d model case which is open as I want it to be modular or recyclable; so I can change the board to create new pedals. It has space for 2 830pin breadboards which can carry components as well as a 9v input, and 2 mono 6.35mm or 1/4" female jacks for input and output of guitar.
